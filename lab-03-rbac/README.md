
# Lab 03 – Microsoft Entra ID Role-Based Access Control (RBAC)

## Objective
Demonstrate how Microsoft Entra ID administrative roles control permissions using the principle of least privilege.

## Lab Environment
- Microsoft Entra Admin Center
- Microsoft Entra ID test tenant
- Non-administrator test user

## Scenario
An IT support employee requires permission to manage user accounts without receiving unrestricted Global Administrator access.

## Planned Activities
1. Review built-in Microsoft Entra ID roles.
2. Assign the User Administrator role to a test user.
3. Verify the role assignment.
4. Review the permissions and scope of the role.
5. Remove the role assignment.
6. Verify role removal in audit logs.

## Implementation Steps
To be documented after completing the practical exercises.

## Validation and Screenshots
Evidence and results will be added as the lab progresses.

## Key Concept
Microsoft Entra ID administrative RBAC controls management permissions. It is different from using security groups to grant access to applications and resources.
