
# Lab 04 – Microsoft Entra ID Joiner, Mover and Leaver (JML)

## Objective
Demonstrate employee identity lifecycle management through user onboarding, department transfer and offboarding in Microsoft Entra ID.

## Lab Environment
- Microsoft Entra Admin Center
- Microsoft Entra ID test tenant
- Fictional test employee
- Finance and HR security groups

## Scenario
An employee joins Finance, transfers to HR and eventually leaves the organization. The IAM administrator manages the employee's identity attributes, group memberships and account status.

## Planned Activities
1. Joiner – Create a user and assign Finance group membership.
2. Mover – Update department and replace Finance membership with HR membership.
3. Leaver – Disable the account and remove remaining group membership.
4. Verify changes using Entra ID audit logs.
