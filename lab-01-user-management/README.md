# Lab 01 – Microsoft Entra ID User Creation and Management

## Objective
Learn how to create, configure, manage, disable and delete test user accounts in Microsoft Entra ID.

## Lab Environment
- Microsoft Entra Admin Center
- Microsoft Entra ID test tenant
- Test user accounts

## Planned Activities
1. Create a new user account.
2. Configure user profile attributes.
3. Verify the newly created user.
4. Update user information.
5. Disable and re-enable the account.
6. Review audit logs.
7. Delete and restore a test user.
