
# Lab 02 – Microsoft Entra ID Security Groups and Membership

## Objective
Demonstrate how Microsoft Entra ID security groups are used to manage user access through group membership.

## Lab Environment
- Microsoft Entra Admin Center
- Microsoft Entra ID test tenant
- Test user accounts

## Scenario
An employee joins the Finance department and requires access through a security group. When the employee transfers to HR, their group membership must be updated to reflect their new responsibilities.

## Planned Activities
1. Create a security group.
2. Add a test user to the group.
3. Verify group membership.
4. Remove the user from the group.
5. Review membership changes in audit logs.
6. Understand Assigned vs Dynamic group membership.
