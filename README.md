# Microsoft Entra ID – IAM Hands-on Labs

## Project Overview
This repository documents my practical learning and implementation exercises using Microsoft Entra ID (formerly Azure Active Directory).

The objective is to strengthen hands-on skills in Identity and Access Management (IAM), including identity lifecycle management, authentication, authorization, application integration, access governance and troubleshooting.

## Technologies
- Microsoft Entra ID
- Microsoft Entra Admin Center
- Microsoft Graph API
- PowerShell
- SAML, OAuth 2.0, OpenID Connect and SCIM

## Lab Documentation
Each completed lab will include:
- Objective and prerequisites
- Configuration steps
- Screenshots using test identities
- Validation and test results
- Troubleshooting and lessons learned

## Progress
This repository is a work in progress. Labs will be updated as practical exercises are completed.

## Security
All demonstrations will use test accounts and fictional information. No production credentials, access tokens, client secrets or confidential tenant data will be published.
